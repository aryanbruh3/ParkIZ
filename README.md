ParkIZ - Smart Vehicle Communication System
ParkIZ is a full-stack solution designed to solve the "wrong parking" dilemma without compromising user privacy. Instead of leaving a phone number on a dashboard, users display a ParkIZ QR code.

🌟 Key Features
Privacy-First Communication: Enables anonymous messaging between a person and a vehicle owner via unique QR code scans.

AI-Powered Spam Filtering: Integrated a machine learning model to detect and block harassing, irrelevant, or spam messages in real-time.

Dynamic QR Generation: Automatically generates unique QR codes linked to user profiles.

Responsive Dashboard: A clean UI for vehicle owners to manage their codes and view filtered notifications.

🛠️ Tech Stack
Backend: Python (Flask)

AI/ML: Scikit-learn / NLTK (Spam Detection)

Frontend: HTML5, CSS3, JavaScript

Database: SQLite / PostgreSQL

Deployment: Gunicorn & Render
